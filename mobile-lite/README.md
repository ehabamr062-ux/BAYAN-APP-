# 📱 تطبيق بيان المحاسبي - نسخة الموبايل لايت (Bayan Mobile Lite)

نسخة ويب تقدمية خفيفة وسريعة جداً **(Progressive Web App - PWA)** مخصصة لشاشات الهواتف الذكية بنظام اللمس، تتيح لمدير أو صاحب المحل متابعة المبيعات والأرباح وإضافة العمليات ومشاركتها عبر واتساب لحظياً من أي مكان.

---

## ✨ المميزات الرئيسية
1. **المزامنة السحابية الحية (Live Firestore Cloud Sync):**
   * ربط فوري بكود السيريال الخاص بالمحل.
   * أي عملية تسجل على كمبيوتر المحل تظهر فوراً على الموبايل، وأي عملية تسجل من الموبايل تنزل في جدول المحل في نفس الثانية.
2. **لوحة تحكم مالية عصرية (Glassmorphism 2.0):**
   * كروت إجماليات: الوارد (المبيعات 🔝)، المنصرف (المصروفات 🔻)، وصافي أرباح اليوم ✨.
   * تفصيلة فورية لطرق الدفع: **كاش نقدي** | **إنستا باي** | **فودافون كاش**.
3. **نافذة إضافة سريعة (Bottom Sheet Modal):**
   * تفتح بحركة لمس سلسة من أسفل الشاشة لإدخال المبلغ وتحديد نوع العملية وطريقة الدفع وحفظها في ثوانٍ.
4. **دعم الوضعين الفاتح والداكن (Dual Theme):**
   * تبديل سلس بنقرة واحدة بين الوضع الداكن الأنيق والوضع الفاتح عالي التباين.
5. **مشاركة فورية عبر واتساب (WhatsApp Share):**
   * إرسال كشف حساب اليوم المنسق بالأرقام والإيموجي إلى واتساب المالك بضغطة زر واحدة.
6. **العمل أوفلاين (PWA Offline Capability):**
   * مزود بـ `manifest.json` و `service-worker.js` لتثبيته كأيقونة تطبيق على شاشة الهاتف وتشغيله بدون إنترنت.

## 🚀 كيفية التشغيل والرفع على GitHub

### 1. التشغيل المحلي:
* يمكنك فتح الملف [index.html](file:///c:/Users/Test/Desktop/BAYAN%20SOFTWARE%20WEBSITE/New%20folder/mobile-lite/index.html) في أي متصفح هاتف أو كمبيوتر.
* أدخل كود السيريال الخاص بمحلك (مثل `BYN-XXXX-XXXX`) لتفعيل المزامنة المباشرة.

### 2. الرفع على GitHub Pages (لجعله متاحاً أونلاين على هاتفك في أي وقت):
* أنشئ مستودعاً جديداً (New Repository) على GitHub باسم `bayan-mobile-lite`.
* ارفع محتويات هذا المجلد `mobile-lite/` بالكامل إلى المستودع.
* من إعدادات المستودع (Settings ➡️ Pages)، فعّل خيار النشر عبر **GitHub Pages**.
* سيمنحك GitHub رابطاً مخصصاً (مثل `https://your-username.github.io/bayan-mobile-lite`) تفتحه من هاتفك المحمول وتضغط **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)** ليعمل كتطبيق جوال أصيل!
